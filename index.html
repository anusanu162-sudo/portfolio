03 — Projects

Things I've actually shipped

Five projects, each one taught me something the previous one didn't.

Final Year Project 01

AI-Assisted Consumer Grievance System

A web app where a consumer describes a complaint and uploads evidence. EasyOCR pulls text out of receipts and warranty cards, spaCy analyses the complaint, and the system drafts a structured complaint that cites the Consumer Protection Act 2019.

  • JWT-based registration and login, complaint records and evidence upload.
  • Drafts are reviewed and filed by the user on e-Daakhil — nothing is auto-submitted.
  • React/Vite frontend with MongoDB Atlas for storage.
  • React
  • MongoDB Atlas
  • EasyOCR
  • spaCy
  • JWT
Web app 02

Django Blog

A server-rendered blog with four Django models linked by a foreign key, database migrations and a Django Admin area for managing content.

  • Pagination and case-insensitive search across title, content and category.
  • Contact form that validates input and stores messages in MySQL.

Accessibility Auditor

A command-line tool and web app that loads a page in a real browser, runs axe-core, and scores accessibility problems out of 100.

  • Exports reports as Markdown, HTML or JSON.

Machine learning 04

Hate Speech Detector

A Streamlit app that labels short text as hate or not hate with a confidence score, using a pre-trained RoBERTa model from Hugging Face.

  • Trained a TF-IDF + PyTorch DNN baseline on the 24,783-tweet Davidson dataset.
  • Compared model versions on 20 hand-checked examples as a sanity check, not a benchmark.
  • Python
  • PyTorch
  • Hugging Face
  • Streamlit

Flask web app 05

Stress Level Analyzer

A Flask web app that asks 10 lifestyle questions — sleep, work hours, screen time, exercise, caffeine, deadlines — and shows an estimated stress level: Low, Moderate or High, with a short message.

  • Each answer carries a fixed point value; the total is scored out of 100 and mapped to a level.
  • Deliberately a rule-based questionnaire, not a trained model — the README says so plainly.
  • Jinja2 templates for the questionnaire and result page, with the scoring logic in one Flask app.
  • Python
  • Flask
  • Jinja2
  • HTML/CSS
